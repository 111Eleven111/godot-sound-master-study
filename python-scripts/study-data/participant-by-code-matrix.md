# Participant-by-code matrix

This is a first-cycle matrix for the post-play interviews. It is based on
[interview-transcription-trimmed.md](./interview-transcription-trimmed.md) and
cross-checked against the preliminary memo in
[my-remarks-from-transcriptions.md](./my-remarks-from-transcriptions.md).

It is an analytic working document, not a frequency table for proving that a
theme exists.

## Coding legend

- `E` — explicit participant evidence in the corrected transcript
- `I` — indirect or interpretive evidence; revisit during theme review
- `—` — not evidenced in the current transcript
- `?` — potentially relevant, but requires audio/transcript verification

## Codes

| Code | Meaning |
|---|---|
| `AUD` | Participant noticed, compared, or remembered audio differences |
| `EXP` | Participant experimented, repeated actions, or explored audio triggers |
| `MAP` | Participant tried to understand mappings, but experienced uncertainty, randomness, or limited predictability |
| `NAV` | Audio provided feedback, navigation information, or influenced route/action selection |
| `AFF` | Audio produced an affective response such as enjoyment, fear, excitement, irritation, or frustration |
| `ATT` | Audio or silence changed attention, focus, immersion, distraction, or concentration |
| `GOAL` | Audio changed the perceived purpose of an action or the game |
| `WORLD` | Audio contributed to atmosphere, worldbuilding, narrative, or a sense of place |
| `GENRE` | Prior genre expectations shaped the participant's interpretation |
| `CTRL` | Participant described audio as responsive, controllable, or insufficiently controllable |

## What this matrix can and cannot support

### It can support

- Comparing how participants described audio exploration, mapping uncertainty,
  feedback, affect, and goal changes.
- Selecting contrasting cases for close analysis, especially Participants 4, 7,
  13, 17, and 18.
- Connecting qualitative accounts to scenario order and telemetry profiles.
- Reviewing whether a candidate theme is supported by diverse cases rather than
  only by the most enthusiastic participant.
- Identifying negative cases, such as Participants 3, 10, 12, and 16, where
  gameplay goals remained more important than audio exploration.

### It cannot support by itself

- Claiming that every `E` entry has equal strength or importance.
- Counting codes as if the interviews were standardized measurements.
- Inferring that a participant understood a mapping merely because they noticed
  a sound.
- Treating event rate as the cause of a participant's interpretation.
- Treating `I` entries as confirmed evidence without returning to the transcript
  or recording.
- Generalizing the matrix to all players without considering the small,
  exploratory sample and the uneven prompting in open-ended interviews.

## Next coding pass

1. Verify every quotation and uncertain transcription against the audio.
2. Replace `I` entries with `E`, `—`, or `?` after verification.
3. Add a column indicating whether each observation was spontaneous or prompted.
4. Split `MAP` into two codes if needed: **mapping comprehension** and
   **mapping predictability/control**.
5. Review the matrix against the candidate themes:
   - audio reconfigures gameplay actions;
   - responsive but partially intelligible sound systems;
   - sound and silence shape attention and emotion;
   - audio mediates navigation and feedback.
6. Use the matrix to select both supporting and contradictory cases before
   writing the thematic findings.
